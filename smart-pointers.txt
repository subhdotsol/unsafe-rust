Smart pointer	Main idea
Box<T>	Heap allocation + single ownership
Rc<T>	Shared ownership, single-threaded
Arc<T>	Shared ownership, thread-safe reference counting
Weak<T>	Non-owning weak reference to Rc/Arc
RefCell<T>	Runtime-checked interior mutability
Cell<T>	Simple interior mutability for Copy-like values
Mutex<T>	Thread-safe interior mutability
RwLock<T>	Multiple readers OR one writer
Cow<'a, T>	Clone-on-write

Box<T>       → one owner, heap
Rc<T>        → multiple owners, single thread
Arc<T>       → multiple owners, threads
Weak<T>      → non-owning reference

Cell<T>      → simple interior mutation
RefCell<T>   → runtime borrow checking
Mutex<T>     → synchronized exclusive access
RwLock<T>    → many readers / one writer

Cow<T>       → clone on write
Pin<T>       → don't move
